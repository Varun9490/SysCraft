## 1. System Overview & Execution Model
**SysCanvas** is a 100% client-side, zero-backend browser application. All graph rendering, discrete-event queuing simulation, OpenTelemetry trace generation, spaced-repetition scheduling (FSRS), persistence, and Infrastructure-as-Code compilation execute inside the user's browser runtime.
